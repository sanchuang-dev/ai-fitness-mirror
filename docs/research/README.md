# AI 健身镜技术研究资料

本目录记录 AI 健身镜从现成模型调研到第一阶段 POC 的研究结论。它是**研究与决策材料，不代表产品能力已经实现**。

## 当前推荐结论

- 不从零训练人体姿态模型；优先复用 MediaPipe Pose Landmarker 等预训练模型。
- 首期只验证深蹲、开合跳、侧平举三类动作。
- 先实现计数、幅度、节奏和有限、可解释的偏差提示；G1 不做百分制“标准度评分”。
- 推荐 C-lite 混合架构：终端本地姿态推理和动作规则，服务端处理课程离线解析、动作模板与版本管理。
- 先批准有预算上限的 42 人日专项 POC，不直接批准整机量产研发。
- 原有 Android 11 无摄像头样机不参与本项目的验证、改造、适配或验收。

## 证据原则

1. 原始 JSON 中的测量值与报告中的估算分开记录。
2. M2 Mac 的结果不能直接外推到低成本 ARM 主板。
3. 姿态检测率不等于动作计数准确率；骨架相似度不等于动作标准度。
4. 没有人工真值标注，不报告动作计数准确率。
5. 模型、权重、运行时、第三方课程和衍生模板分别核对商用授权。

## 当前产品状态

仓库现有 prototype 仍是静态 H5 原型。研究文档不改变该状态，也没有接通摄像头、真实课程服务或 AI 推理链路。
